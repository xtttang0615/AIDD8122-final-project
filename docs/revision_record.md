# 修订记录（Revision Record）

本文件记录本轮审查发现的问题、证据、修改、受影响文件与重跑范围。
**本修订分析计划形成于结果复算之前，不构成研究开始前的预注册。**

## 0. 修订定位

项目定位修正为：**转录组靶点发现与配体药物排序流程的探索性研究及可靠性评价**。
不声称已验证的 AMI 治疗靶点、不声称 pipeline 无泄漏、不声称已证明靶点特异性。

## 1. A｜MI 药物打分的分子身份对应（已修复）

- **问题**：`src/14_score_mi_drugs.py` 中特征化失败会跳过分子，随后用
  `gold.iloc[:len(G_fp)]` 截取前 N 行与预测结果对齐，无法保证身份一致。
- **证据**（`results/tables/audit_mi_identity.csv`）：
  - 有结构分子 123 个，特征化成功 108 个，失败 15 个（盐类/离子/多肽等）。
  - 失败分子分布于列表中部，**`iloc[:108]` 与真实成功集合相差 14 个 ID（双向各 14）**，
    判定 `identity_mismatch_by_truncation = True`。
  - 与归档表逐键比对：324 行中 282 个键可比，**224 行概率发生变化**；
    另有 42 行属于截断产生的“幽灵 ID”。
- **修改**：`featurize()` 返回成功行号；`gold = gold.iloc[g_idx]`，失败记录写入
  `results/tables/mi_drug_featurize_failed.csv`。
- **影响**：历史表归档为 `mi_drug_scores_legacy_misaligned.csv`，新版覆盖
  `mi_drug_scores.csv`。**聚合统计未变**（同一批 108 个分子，分数多重集相同），
  变化的是逐分子 ID→分数对应。
- **定位**：该脚本以训练诱饵为比较背景，**不作为独立验证**；原“19.6 倍富集、
  p≈1e-34”不再作为可靠性或药物有效性证据，仅在审查记录中说明其局限。

## 2. B｜MI 适应证集合的定义（已修正表述）

- 原称“已获批 AMI 药物金标准”不准确：该集合来自 ChEMBL `drug_indication` 检索，
  混有已上市与临床阶段分子，且分子总体 `max_phase` 不等于 AMI 适应证获批。
- 检索方式：`efo_id=EFO_0000612` 命中 0 条 → 改用 `efo_term__contains="myocardial infarction"`，
  命中 191 条适应证记录。
- 完整漏斗：**191 条适应证记录 → 161 个分子 → 有结构 123 → 标准化可用 108
  → InChIKey14 去重 89**。
- 现统一称“**ChEMBL 中具有 MI 适应证记录的分子**”，富集检验定位为
  **探索性适应证关联检查**。
- 未按结果挑选“AMI 适应证获批”子集；如需补充分析，只能按适应证层面阶段预先定义。

## 3. C｜候选/评价集与全部训练数据的重叠（已修复）

- **问题**：原 `20_build_approved_pool.py` 只排除 `pool_actives`（训练正例），
  未排除 `pool_decoys`（训练负例）。
- **证据**（`results/tables/audit_overlap.csv`，InChIKey14 结构键）：
  - `approved_pool` 与训练负例重叠：PDE4B 61、PFKFB3 17、EPAS1 26、PDK4 6；
    与训练正例重叠 0。
  - `mi_gold`（89）与训练负例重叠：PDE4B 3、EPAS1 1，其余 0。
- **修改**：
  - `22_mi_enrichment.py`：逐靶点剔除与该模型全部训练数据（正例+负例）重叠的分子；
    共识分析使用对三个模型均未见过的共同集合。
  - `23_shortlist.py`：聚合排名剔除与任一模型训练数据重叠的分子（1905 → 1823，剔除 82）。
- **影响**：模型未重训（仅评价集合调整），排名、分母、富集指标与图已更新。
- 修订后结论：MI 适应证分子在四个评分维度上**均未观察到富集**
  （auc_like 0.48–0.50，p 0.48–0.75），与修订前一致，方向未变。

## 4. D｜困难基准的合并分折（已修复）

- **问题**：原实现合并不同靶点数据后直接沿用各自独立生成的折号，
  不能保证合并集合内骨架隔离。
- **检查结果**：原折号下跨折冲突未被实际观察到（无同骨架/同结构跨折），
  但该保证依赖偶然性，方法上不成立。
- **修改**：新增 `src/18b_hard_benchmark_v2.py`，先构建完整困难基准，再统一
  `StratifiedGroupKFold(5, seed=42)`；新切分写入
  `data/processed/hard_benchmark_splits.csv`，**原 `scaffold_splits.csv` 保留**。
- **复核**：三个靶点跨折 scaffold = 0、InChIKey14 = 0、标签冲突结构 = 0。
- **新结果**：PDE4B PR-AUC 0.9975（ROC 0.9978）、PFKFB3 0.9966（0.9992）、
  EPAS1 0.9867（0.9941）。原表归档为
  `results/tables/ligand_model_hard_benchmark_legacy.csv`。
- **限定**：其他靶点配体只是“假定困难负例”，不等于该靶点实测非活性分子；
  不得据此声称已证明生物学靶点特异性；prevalence 变化影响 AP，
  lift 不能被描述为完全消除阳性比例影响。

## 5. E｜转录组分支的表述（仅修正表述，未重跑）

- 探针选择（取平均表达最高探针）在 **GSE66360 全 99 例**上完成，
  外部队列独立选择；该数据依赖预处理会带入发现集信息，故整体定位为探索性。
- 删除“所有预处理严格隔离”“完全不存在泄漏”等绝对表述。
- 稳定性筛选：主筛选 bootstrap **200 次**；完全嵌套 CV 的每个外层折 **100 次**。
- 区分两条流程：①全发现集固定十基因模型；②每折重新筛选基因的嵌套 CV。
  **0.961 属于后者**，不能直接称为固定十基因模型的独立性能。
- 分类器曾在发现集上比较选定，模型选择过程未整体纳入外层评价。
- 阈值 0.6001 来自早期全发现集筛选后的 OOF 预测并沿用，不是当前完整嵌套流程
  独立优化的阈值；未在内部/外部验证队列重新寻优。
- bootstrap 置信区间是对已有预测的重采样，不包含建模与特征选择的不确定性。
- z-score 敏感性分析涉及重新拟合标准化后的模型，并使用外部队列自身无标签统计量，
  不是“只改阈值”或“单样本可直接部署”。

## 6. F｜无效消融与 PDK4 重复评价（已修复）

- **A3 阈值敏感性为 no-op**：PDE4B 已按 pChEMBL 截断取前 800，最小值 7.58，
  `pChEMBL>=7` 不改变样本集合。现标记为 `no-op`、指标置空、不作比较；
  代码加入“样本集合是否变化”的检查。未为此重建全部配体训练集。
- **PDK4 重复拟合**：原 `run_cv` 对 hold-out scheme 遍历 fold=0/1，
  同一测试集被拟合并记录两次。现 hold-out 只跑一次，逐折表每模型仅 1 行。
- 保留 ECFP4、描述符、二者组合与多分类器的有效比较。
